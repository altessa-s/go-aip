# Errors (AIP-193)

[apierror](../apierror/) implements the AIP-193 error model on the genproto `google.rpc` messages, without a gRPC dependency and without
go-atlas packages other than `go-atlas-core/errors`. [apierror/aipmap](../apierror/aipmap/) maps the sentinels of the go-aip packages.

## Transport wiring

* gRPC: `return status.FromProto(mapper.Map(err).Proto()).Err()` in a unary interceptor or handler. go-atlas has its own errstatus
  interceptor; the default rules of `apierror` use the same codes, messages and reasons as its canonical rules.
* HTTP/JSON: `mapper.Map(err).WriteHTTP(w)` writes the AIP-193 body with the HTTP status of the code.
* Clients and proxies: `apierror.FromProto(st)` reads a status back; unknown detail types stay packed.

## Conformance

| AIP-193 rule                                                                                         | Level  | Implemented by                                   | Behavior                                                                                                                                                                                                                                                                                                               |
|------------------------------------------------------------------------------------------------------|--------|--------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Errors are `google.rpc.Status` with a `google.rpc.Code`                                              | MUST   | `Error.Proto`, `New`                             | `New` refuses `OK` and codes outside the enum (`ErrInvalidError`).                                                                                                                                                                                                                                                     |
| `message` is a developer-facing, human-readable debug message in English                             | SHOULD | `New`, default rules                             | Non-empty UTF-8 required; the mapped messages are fixed English sentences. Localized text goes in `LocalizedMessage`.                                                                                                                                                                                                  |
| Messages help a technical user resolve the problem without exposing internals                        | SHOULD | `Mapper`                                         | Fixed messages unless a rule exposes client input, cut to `MaxExposedMessageLength` (1024) runes; an unmatched error is `INTERNAL` / `internal error` (`WithExposeUnknown` is an opt-in).                                                                                                                              |
| Dynamic parts of the message are in `ErrorInfo.metadata`                                             | MUST   | `WithMetadata`                                   | The caller puts every variable in metadata; mapped messages carry none besides exposed client input (the request's own values).                                                                                                                                                                                        |
| Every error includes `ErrorInfo`                                                                     | MUST   | `New`, `Mapper.Map`, `FromProto`                 | Always present and first; the reason defaults to the code name; `FromProto` refuses a status without it.                                                                                                                                                                                                               |
| `reason` is UPPER_SNAKE_CASE, ≤ 63 characters, `[A-Z][A-Z0-9_]+[A-Z0-9]`                             | MUST   | `New`, `NewMapper`, `ValidReason`                | Validated on every error, every rule and every field-violation reason.                                                                                                                                                                                                                                                 |
| `domain` is a globally unique service name                                                           | MUST   | `WithDomain`, `WithDefaultDomain`                | The service configures it once on its mapper; an `*Error` without a domain gets it on a copy. No package default (a library cannot know it).                                                                                                                                                                           |
| Metadata keys are lowerCamelCase, ≤ 64 characters, `[a-z][a-zA-Z0-9-_]+`                             | MUST   | `New`, `ValidMetadataKey`                        | Validated.                                                                                                                                                                                                                                                                                                             |
| Existing metadata keys keep appearing (possibly empty)                                               | MUST   | —                                                | API-evolution rule for the service; documented.                                                                                                                                                                                                                                                                        |
| A brownfield message stays stable if clients parsed it                                               | MUST   | default rules                                    | The default messages are exported constants and match go-atlas.                                                                                                                                                                                                                                                        |
| Each detail type appears at most once                                                                | MUST   | `New`, `FromProto`                               | One slot per standard type; duplicates of any type (packed `Any` included, by type URL) are refused.                                                                                                                                                                                                                   |
| `LocalizedMessage` has both `locale` (BCP-47) and `message`                                          | MUST   | `WithLocalizedMessage`, `New`                    | Both required, also inside a `BadRequest.FieldViolation`. The locale's BCP-47 syntax is not parsed.                                                                                                                                                                                                                    |
| `BadRequest` names the offending request field                                                       | SHOULD | `Mapper.Map`, `aipmap`                           | A `coreerrs.FieldError` becomes a field violation with the path as produced (`updateMask.paths[i]`, `requests[i].x`) and the rule's reason; with `aipmap`, a fieldinfo, fieldbehavior or fieldmask violation list becomes one violation per field, reason per format (`INVALID_UUID4`) or behavior (`REQUIRED_FIELD`). |
| `DebugInfo` is not sent to clients                                                                   | SHOULD | `Proto`, `JSON`, `Details`                       | Rendered only with `WithIncludeDebugInfo(true)`.                                                                                                                                                                                                                                                                       |
| `PERMISSION_DENIED` when the caller lacks access, whether or not the resource exists; then NOT_FOUND | MUST   | —                                                | Ordering of checks is the service's; `New(code.Code_PERMISSION_DENIED, ...)` or a rule on its own sentinel.                                                                                                                                                                                                            |
| HTTP/JSON: `code` is the HTTP status, `status` the code name, details carry `@type`                  | MUST   | `JSON`, `MarshalJSON`, `WriteHTTP`, `HTTPStatus` | Code→HTTP per `google/rpc/code.proto` (CANCELLED 499); details in protojson.                                                                                                                                                                                                                                           |
| Partial errors are avoided; when needed, per-item `google.rpc.Status` in LRO metadata                | SHOULD | `Error.Proto`                                    | No partial-error type; a batch builds one `Proto()` per item.                                                                                                                                                                                                                                                          |

## Mapping

| Source                                            | Result                                                                                                                                                                                                                                                                                                                    |
|---------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `*apierror.Error` in the chain                    | Returned as is (domain filled in on a copy).                                                                                                                                                                                                                                                                              |
| `coreerrs.ErrNotFound`                            | NOT_FOUND `NOT_FOUND`                                                                                                                                                                                                                                                                                                     |
| `coreerrs.ErrAlreadyExists`                       | ALREADY_EXISTS `ALREADY_EXISTS`                                                                                                                                                                                                                                                                                           |
| `coreerrs.ErrConflict` (AIP-154 stale etag)       | ABORTED `VERSION_CONFLICT`                                                                                                                                                                                                                                                                                                |
| `coreerrs.FieldError`                             | INVALID_ARGUMENT, `<field>: <reason>`, BadRequest field violation                                                                                                                                                                                                                                                         |
| `coreerrs.ErrInvalidArgument`                     | INVALID_ARGUMENT, the error's text                                                                                                                                                                                                                                                                                        |
| `coreerrs.ErrFailedPrecondition`                  | FAILED_PRECONDITION `FAILED_PRECONDITION`                                                                                                                                                                                                                                                                                 |
| `coreerrs.ErrUnavailable`                         | UNAVAILABLE `TEMPORARY_UNAVAILABLE`                                                                                                                                                                                                                                                                                       |
| `coreerrs.ErrBusy`                                | ABORTED `BUSY`                                                                                                                                                                                                                                                                                                            |
| `context.Canceled` / `context.DeadlineExceeded`   | CANCELLED / DEADLINE_EXCEEDED                                                                                                                                                                                                                                                                                             |
| go-aip sentinels                                  | `aipmap.Rules()` — see [the aipmap table](../apierror/aipmap/README.md#rules)                                                                                                                                                                                                                                             |
| go-aip client input (`aipmap`)                    | INVALID_ARGUMENT with a reason per family: `INVALID_FILTER`, `INVALID_ORDER_BY`, `INVALID_READ_MASK`, `INVALID_FIELD_MASK`, `FIELD_BEHAVIOR_VIOLATION`, `INVALID_FIELD_FORMAT`, `INVALID_ETAG`, `ETAG_REQUIRED`, `INVALID_PAGE_TOKEN`, `INVALID_RESOURCE_NAME`, `INVALID_BATCH`, `*_TOO_COMPLEX`, `MESSAGE_TOO_DEEP`, ... |
| go-aip server faults (`aipmap`)                   | INTERNAL `internal error`: missing policies, invalid schemas or options (the meili version check included), validateonly misuse, etag helpers on a message without an etag field, invalid fieldinfo registrations                                                                                                         |
| `etag.ErrMismatch` (wraps `coreerrs.ErrConflict`) | ABORTED `VERSION_CONFLICT` (AIP-154)                                                                                                                                                                                                                                                                                      |
| anything else                                     | INTERNAL `internal error`                                                                                                                                                                                                                                                                                                 |

Service rules (`WithRules`) are evaluated first, then `DefaultRules()`; the first `errors.Is` match wins.

An `apierror.Classified` error (`apierror.Classify(category, cause)`) reads as its category, unwraps to the category alone and hides its
cause: errors.Is, errors.As and its text never reach the cause, so the mapper matches rules and looks for an `*Error` and a FieldError in
the category only, and no code that walks the chain (`coreerrs.MapFieldPath`, `batch.ItemError`, a converter, a wrapper formatting the
error with any verb, `%#v` included) can expose a FieldError, sentinel or text of the cause. `apierror.HiddenCause` returns the cause for
logs and diagnostics, through the mapped error as well, and the error renders `<category>: <cause>` as a `slog.LogValuer`. The MongoDB and
SQL list engines classify a stored record that does not decode this way, so a decoder's page-token, deadline or field error stays an
INTERNAL fault, and errors.Is(err, context.DeadlineExceeded) is false for it. They also hide the driver error of a query that timed out
or whose context ended behind the context's error or their `ErrTimeout`, so no backend text reaches the client. A
`coreerrs.FieldError` above a classified error is an ordinary client error: the code that built it had no access to the cause.

`aipmap` keeps an exhaustive table of the module's exported sentinels and error types with the code and reason each maps to; a test parses
the module and fails when a new exported `Err*` variable or error type is missing from it, so every sentinel gets a rule or a deliberate
fall-through to the default rules.
