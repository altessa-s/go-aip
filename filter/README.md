# filter

```go
import "github.com/altessa-s/go-aip/filter"
```

Shared filter AST, field types and immutable policy construction. Parsing, in-memory evaluation and backend translation live in separate packages;
importing this package does not import CEL, an evaluator, telemetry or a database driver.

## Contract

Construct an immutable `Policy` with `NewPolicy` and validate a shared `Node` AST before evaluation or translation. A nonempty field allowlist is
required unless `WithAnyField(true)` explicitly permits trusted fields. `WithUntrustedInput(true)` always requires an allowlist and disallows unsafe
regex configuration. A `WithFieldAccess` policy counts as the allowlist only when it restricts the fields: a `fieldpolicy.AllowList` that is
configured, nonempty and neither `*` nor stars only (`AllowList.Restricts`), or, on trusted input only, an opaque `fieldpolicy.Access`. Without
one `NewPolicy` fails with `ErrAllowlistRequired`, and every translator and evaluator constructor fails with `ErrPolicyRequired` for a nil
policy ([Errors](#errors)).

Every field reference is a dotted path of plain identifiers (`[A-Za-z_][A-Za-z0-9_]*` per segment), as in orderby and projection: the parser
refuses CEL backtick escapes that are not plain identifiers (``a.`b c` ``, ``a.`b.c` ``) and root-scoped names (`.a`), and
`CheckFieldReference` — run by validation and every translator — refuses any other name with `ErrInvalidExpression`, including names of hand-built
ASTs. `Policy.DeclaresField` tells a field the service named (allowlist, field type or storage mapping) from one only a wildcard admits, for
renderers that read a dot as SQL qualification.

A policy holds what the client may ask for, in CEL-side (API) names, independent of any backend: build it once per resource and pass it to
every translator and evaluator. Storage names are a translator concern: `NewTranslatorContext(policy, opts ...TranslatorOption)` returns a copy
(a `*Policy`) bound to one backend's names (`WithFieldMapping`), leaving the shared policy unchanged; it
fails with `ErrPolicyRequired` for a nil policy.
See [Parser / policy / translator](../docs/filter.md#parser--policy--translator).

`ExtensionNode.Lower` returns an equivalent built-in AST without cycles. Snapshots lower extensions before caching, so validation, translation,
evaluation, and canonicalization use the same meaning. Implementations expose dependencies through `Children` and support concurrent calls.

`WithValueCodecs` registers literal validation for application field kinds. `WithDecimalParser` replaces decimal conversion for scalar
and membership operands. Immutable custom enum literals do not require a codec just to validate; renderers still need a supported storage
representation. Cached values cannot retain mutable references; byte slices are copied.

`WithPortableContract(true)` selects portable listing validation. `WithContractRules` overrides individual rules without disabling the rest. These
rules constrain literal comparisons, bare booleans, membership, null operands, and regex shapes; see `ContractRule` constants in the API.
Backend-native behavior remains available when the portable preset is disabled.

Regex validation, compilation, and caching are instance dependencies. `WithRegexCompiler` supplies a concurrency-safe compiler that owns its cache;
`WithRegexValidator` replaces safe-subset validation. The built-in cache holds 256 patterns; zero disables it. `WithSafeRegex(true)` admits safe
patterns for untrusted input, while `WithUnsafeRegex(true)` is only compatible with trusted input. Length and AST limits still apply.

Wrapped parser, regex, codec, and translator failures preserve their causes. Use `errors.Is` and `errors.As` for classification. `Canonical` preserves
literal types and boundaries for bindings; `Clone` returns a detached AST.

## Usage

```go
import (
    "github.com/altessa-s/go-aip/filter"
    "github.com/altessa-s/go-aip/filter/evaluator"
    filterparser "github.com/altessa-s/go-aip/filter/parser"
)

p, err := filterparser.New()
if err != nil {
    return err
}
node, err := p.Parse(ctx, `age >= 18`)
if err != nil {
    return err
}
policy, err := filter.NewPolicy(
    filter.WithAllowedFields("age"),
    filter.WithFieldTypes(map[string]filter.FieldKind{"age": filter.FieldKindInt}),
)
if err != nil {
    return err
}
eval, err := evaluator.New(policy)
if err != nil {
    return err
}
matched, err := eval.Evaluate(node, map[string]any{"age": int64(21)})
```

Every backend is its own Go module (`backend/<db>`), so the root module requires no database driver.

### Translator ports

The backend-neutral ports live in this package so that every backend package depends only on `filter`:

| Port              | Contract                                                                               |
|-------------------|----------------------------------------------------------------------------------------|
| `Translator[Out]` | `Translate(Node) (Out, error)`: one rendered query value                               |
| `Compatibility`   | `ValidateAST(Node) error` checks the configured backend: shape, policy, literal values |
| `metrics.TranslateTimer`       | `NewTelemetry(meter, backend)` records `filter_<backend>_translate_duration_seconds`   |

A nil meter disables `metrics.TranslateTimer`; a nil `*metrics.TranslateTimer` is a valid disabled receiver.

### SQL translators

`clickhouse`, `mariadb` and `postgres` share one AST walk and differ only in a `Dialect` — see
[`backend/sqlbase`](../backend/sqlbase/#filter-predicate-builder). Their `Translate` returns three values, `(where string, args []any, err error)`:
literals leave the SQL text entirely and come back as bind arguments aligned with their placeholders, so a clause built from request data cannot alter
the shape of the query. PostgreSQL numbers its placeholders (`$1`, `$2`, …); the other two use positional `?`.

```go
where, args, err := trans.Translate(ast)
rows, err := conn.Query(ctx, "SELECT * FROM events WHERE "+where, args...)
```

`TranslateInline` renders the same clause with literals in place, for the cases a placeholder cannot serve — view definitions, generated DDL, logs. A
`nil` AST translates to `1 = 1` in both modes, so the concatenation above needs no special case.

Dialect differences worth knowing before choosing a filter surface: MariaDB's default collations make every string predicate case-insensitive,
PostgreSQL requires a real `boolean` column for a bare-identifier condition, and only ClickHouse reads a dotted CEL name as a single (Nested) column
rather than a qualified `"table"."column"`. Each package README covers its own.

### Policy validation changes

`Policy.Field(name)` returns a value whose `Allowed()` result belongs to that policy. `Policy.AllowsField` was removed;
callers cannot pass another policy's compiled field back for authorization. `FieldPolicy.CheckLiteral` now takes only the literal.
`CheckSizeOperand` and `MaxSizeOperand` moved to [backend/mongo](../backend/mongo/README.md).

`Evaluate`, `Validate` and `Prepare` enforce the allowlist across the complete expression, including skipped branches.
MongoDB storage semantics are declared in `mongo.Schema` (backend/mongo), separate from `filter.Policy`.

### Backend-neutral validation

`filter.Validate(node, policy)` checks the filter shape shared by translators and evaluators: field references are allowed, comparison
values are literals of supported types, decimal operands are exact, string functions have one string argument, and `size()` appears only
inside a comparison. It also checks the policy's expression limits. Backend-specific constraints, such as MongoDB's `size()` operand
range, remain in the backend validator.

Pass `filter.WithPortableContract(true)` when constructing the policy to enable listing's portable rules: `in` lists are non-empty and do
not contain `null`, ordered comparisons do not use `null`, and `matches()` uses only escaped literal characters, `^`, `$` and `.*`,
with an optional leading `(?i)` for an ASCII-only pattern (as `functions.TextSearch` emits). A bare identifier is accepted as a
predicate only for a scalar bool field. For declared arrays, `== null`, `!= null` and `has()` follow the empty/non-empty array
contract. The option is disabled by default, so existing translator and evaluator callers retain their current behavior.

```go
policy, err := filter.NewPolicy(
    filter.WithAllowedFields("name", "age"),
    filter.WithPortableContract(true),
)
if err != nil {
    return err
}
if err := filter.Validate(node, policy); err != nil {
    return err
}
```

## PostgreSQL parity

`postgres.Schema` (backend/postgres) owns PostgreSQL's typed schema and compiled `Program`. The program compiles a filter once and can render SQL or
evaluate in-memory rows with PostgreSQL's array and JSONB behavior; both give NULL the default evaluator's semantics, so they agree on every row.
`postgres.NewFilterTranslatorWithSchema` is the translator-facing wrapper; `evaluator.WithProfile` lets the evaluator use the same schema.
`sqlbase.Decoder` handles nullable SQL and driver values. See the [PostgreSQL schema contract](../backend/postgres/README.md) for collation, array
bounds and exact JSON-number input. The scalar `postgres.NewFilterTranslator` needs no schema.

## Negation normal form

`filter.NegationNormalForm(node, arrayFields, invertibleFields)` returns a deep AST copy with logical negation pushed to predicate
leaves. It applies De Morgan's laws and removes double negation. Comparison leaves are inverted only when their field is in
`invertibleFields`; other leaves keep an explicit `!` to preserve backend null behavior. Array membership leaves and string-function
leaves also retain an explicit `!` because their complements are backend-specific. Both field sets map declared names to `true`.

## Extension contracts

| API                               | Purpose                                                                  |
|-----------------------------------|--------------------------------------------------------------------------|
| `ExtensionNode.Lower`             | Expand custom nodes or operators into built-in AST before parser caching |
| `Canonical(Node) (string, error)` | Compute a complete fingerprint or reject unsupported nodes               |

Boolean policy options take explicit values, so later options can reverse presets. Default decimal syntax is independent of Decimal128;
MongoDB translation checks representability when encoding BSON. Default decimal resource limits bound coefficient size, input length,
float precision and exponent work. An injected decimal parser defines an application's alternative policy.

Lowering must produce an acyclic equivalent built-in tree. Custom backend operations without a built-in equivalent belong in a custom
compiler profile. Custom codecs and compiler callbacks must be safe for concurrent use.

## Consistency contracts

Wrapped parser, regex, codec, and translator errors retain their underlying causes for errors.Is and errors.AsType. Policy.Field resolves shared
access rules for undeclared fields as well as declared metadata.

Cached literals may contain immutable scalars, arrays, and structs. Mutable references are rejected; byte slices are copied.
Canonical literal encodings preserve type and component boundaries, including token bindings. Custom comparison applies to membership too.

## Policy propagation

Validation accepts immutable custom enum literals produced by parser vocabularies without requiring a value codec. Declared field kinds and enum
membership rules still apply; backend renderers remain responsible for encoding supported storage values.

Decimal literal validation and conversion share `Policy.DecimalOperand`. `Policy.NormalizeDecimalOperand` applies that policy to scalar or list
operands without mutating their AST and clears consumed source spelling before encoding. Backend encoders validate their storage range on the
converted decimal, rather than reparsing the original literal. Null comparison retains native null semantics.

Backend regex rewrites apply only to the default RE2 compiler (`Policy.UsesRE2Regex`). A custom compiler supplies backend-compatible
syntax and matching semantics; its patterns pass through without RE2 anchor or mode rewrites.

`filter.PolicyOption` configures the immutable field and expression policy shared by evaluators and translators. Common policy rules include field
allowlists, field and enum types, expression limits, and regex safety. Storage names are not among them: `filter.TranslatorOption`
(`WithFieldMapping`, default identity mapping) binds a policy to one backend through `NewTranslatorContext` or the backend's `WithFilterOptions`. A
non-empty allowlist is required unless `WithAnyField` explicitly opts out; `WithUntrustedInput` always requires an allowlist.

The same option type also carries array declarations. `WithArrayFields` describes array-valued fields for MongoDB and compatible evaluation; the
typed PostgreSQL schema validates it against declared array columns. MongoDB missing-value rules live in [backend/mongo](../backend/mongo/README.md)
(`mongo.NewSchema`) and are passed as a schema to MongoDB translation and MongoDB-mode evaluation. They cannot be passed to another backend through
`filter.PolicyOption`. Evaluator execution settings belong to `evaluator.Option` and cannot be passed to a translator.

`Clone` lowers `ExtensionNode` values, copies built-in AST nodes and byte literals, and rejects unsupported custom nodes or mutable literal types.
`Canonical` provides a stable expression representation. Callers own AST mutation; see the parser's `Parse` / `ParseShared` ownership contract.

## Errors

All sentinels match with `errors.Is`; wrapped causes stay reachable. The table matches the [filter guide](../docs/filter.md#errors).

| Error                      | When                                                                                                                      |
|----------------------------|---------------------------------------------------------------------------------------------------------------------------|
| `ErrParseFailed`           | CEL grammar / syntax errors at parse time                                                                                 |
| `ErrEmptyExpression`       | Empty or whitespace-only input                                                                                            |
| `ErrExpressionTooLong`     | Input above `WithMaxExpressionLength`                                                                                     |
| `ErrInvalidExpression`     | Structurally invalid AST (wrong arity, nil node from custom handler, a field that is not a plain dotted path, etc.)       |
| `ErrUnsupportedOperation`  | Operator/function not supported by the target translator (e.g., regex `matches` on Lua)                                   |
| `ErrUnsupportedType`       | Literal type not representable in the target backend                                                                      |
| `ErrFieldNotAllowed`       | Field outside `WithAllowedFields` or denied by `WithFieldAccess`                                                          |
| `ErrFunctionNotAllowed`    | Function outside `WithAllowedFunctions` (built-in or custom); `matches()` under untrusted input without `WithSafeRegex`   |
| `ErrFieldTypeMismatch`     | Literal type does not match the kind declared via `WithFieldTypes`                                                        |
| `ErrEnumValueNotAllowed`   | Integer literal outside the set declared via `WithEnumValues`                                                             |
| `ErrAllowlistRequired`     | `NewPolicy` without a nonempty allowlist or restricting `WithFieldAccess`, unless trusted input opts out (`WithAnyField`) |
| `ErrMaxDepthExceeded`      | AST nesting above `WithMaxDepth`                                                                                          |
| `ErrMaxOperationsExceeded` | Visits above `WithMaxOperations`                                                                                          |
| `regexanchor.ErrInvalidRegex`          | Pattern fails RE2 compilation, exceeds `WithMaxRegexLength` or falls outside the safe subset                              |
| `ErrDataLimitExceeded`     | Evaluation reads more data than `evaluator.WithMaxDataBudget` allows                                                      |
| `ErrPolicyRequired`        | A translator or evaluator built with a nil policy                                                                         |
| `ErrInvalidOptions`        | Contradictory or malformed options (a pattern in `WithAllowedFields`, `WithUnsafeRegex` with untrusted input)             |

## API

| Symbol                 | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `Clone`                | Clone lowers extensions and copies the built-in AST and byte literals. Other custom nodes and mutable literal types fail instead of aliasing the cache.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ContractRule`         | ContractRule identifies one independently configurable validation rule.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `ValueCodec`           | ValueCodec validates a literal for an application-defined FieldKind. Values must have a deterministic representation and be supported by the selected backend.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `DecimalLiteral`       | DecimalLiteral returns v as an exact decimal, the way `FieldKindDecimal` reads an operand: - a decimal.Decimal; - an integer (int64, uint64, int32, int) exactly; - a float64 as the shortest decimal that round-trips to it ("0.1" for the float parsed from 0.1), provided it has at most `MaxExactFloatDigits` significant digits — a longer one cannot be told apart from its neighbors, so write it as a string; NaN and infinities are rejected. A float parsed from a filter expression is read from its source spelling instead (`DecimalOperand`); - a string in decimal notation ("12.30", "-1e-2"), within the default coefficient budget. |
| `DecimalOperand`       | DecimalOperand is `DecimalLiteral` for an operand produced by node: a float literal parsed from an expression is read from its exact source spelling (`1.00000000000000001` stays 1.00000000000000001 although the float it parsed to is 1), bounded like a decimal string; any other node uses v. Translators of `FieldKindDecimal` fields call it with the literal node and its value.                                                                                                                                                                                                                                                              |
| `DepthGuard`           | DepthGuard bounds how deeply a `Visitor` recurses into an expression. A filter arrives from outside the process, so its nesting is an input like any other: unbounded, a few kilobytes of parentheses become a stack overflow.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `NewDepthGuard`        | NewDepthGuard returns a `DepthGuard` that admits limit levels of nesting, taken from `Policy.MaxDepth`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `NodeKind`             | NodeKind represents the type of AST node.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `LiteralNode`          | LiteralNode represents a literal value (string, number, bool, nil).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `IdentNode`            | IdentNode represents an identifier or field reference.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `BinaryOpNode`         | BinaryOpNode represents a binary operation (comparison, logical, membership).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `UnaryOpNode`          | UnaryOpNode represents a unary operation (negation).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `CallNode`             | CallNode represents a function/method call.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `ListNode`             | ListNode represents a list literal.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `Walk`                 | Walk traverses the AST in depth-first order, calling fn for each node. If fn returns false, traversal stops: no further node is visited.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `IsFieldReference`     | IsFieldReference reports whether n can name a field: an identifier, or a size() call, whose target a translator resolves the same way. Translators resolve a field operand only after this check, so a string literal on the field side of a comparison — `"$where" == "x"` — cannot bypass the allow-list and field mapping applied to identifiers.                                                                                                                                                                                                                                                                                                  |
| `NegationNormalForm`   | NegationNormalForm returns a deep copy of node with negations pushed to predicate leaves. arrayFields identifies fields whose membership predicates must retain an explicit OpNot.                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `CheckFieldReference`  | CheckFieldReference returns nil when n is a field reference (see `IsFieldReference`) and otherwise the error a translator reports for n in field position: `ErrUnsupportedOperation` for a function call the backend cannot use there (substring(), …), `ErrInvalidExpression` for anything else (a literal, an operator, a missing node) and for a field that is not a dotted path of plain identifiers (`IsFieldPath`).                                                                                                                                                                                                                             |
| `KindsComparable`      | KindsComparable reports whether operands of two declared kinds can compare equal; translators reject other pairs with `ErrFieldTypeMismatch`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `IsFieldPath`          | IsFieldPath reports whether name is a dotted path of plain identifiers, each segment matching `[A-Za-z_][A-Za-z0-9_]*`: the field grammar `CheckFieldReference` holds every field reference to.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `AllNodes`             | AllNodes returns an iterator over all nodes in the AST in depth-first order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `CountNodes`           | CountNodes returns the total number of nodes in the AST.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `Depth`                | Depth returns the maximum depth of the AST.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

Lower returns an equivalent built-in AST, without cycles.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `RegexMatcher`         | RegexMatcher is the immutable matching result of an injected compiler.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `Regex`                | Regex is an immutable matcher admitted by a policy.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

| `CheckPortableRegex`   | CheckPortableRegex applies the `PortableRegex` contract rule: `regexp.QuoteMeta` text, `^`, `$` and `.*`, an optional leading `(?i)` (whose pattern must be ASCII; case-sensitive text may be Unicode); other patterns fail with `ErrUnsupportedOperation`.                                                                                                                                                                                                                                                                                                                                                                                           |
