# go-aip

```go
import "github.com/altessa-s/go-aip"
```

Helpers for building APIs that follow the [Google API Improvement Proposals](https://google.aip.dev): filtering (AIP-160), ordering
(AIP-132), partial responses (AIP-157), pagination (AIP-158) and field masks (AIP-134, AIP-161).

The module is a skeleton: the packages land here one by one.

## Installation

```sh
go get github.com/altessa-s/go-aip
```
